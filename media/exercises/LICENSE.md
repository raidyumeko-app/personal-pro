# Exercise demonstration media

The MP4 and JPEG files in this directory are adaptations of exercise videos
by **Goulart**, distributed by wger under **Creative Commons Attribution
ShareAlike 4.0 International**:
https://creativecommons.org/licenses/by-sa/4.0/

Original author and license were retrieved from wger's public video API and
license API on 2026-10-19. Each exact original video URL and API entry is
recorded in `../../exercise-media.js`. Exercise identity was checked against
wger's exerciseinfo endpoint before mapping.

Changes: videos converted to H.264 MP4 for browser playback, reduced resolution
and frame rate, audio removed; JPEG posters extracted from the corresponding
video. The adapted media retains the CC BY-SA 4.0 license. No change was made
to movement order or speed. These media files do not change the license of the
surrounding application code.

Media: 73 bench press; 75 dumbbell bench press; 91 barbell curl; 371 leg press;
512 seated cable row with narrow grip; 537 incline dumbbell press;
538 incline barbell press; 348 lateral raises.

Source API: https://wger.de/api/v2/video/?limit=1000&format=json
License API: https://wger.de/api/v2/license/2/?format=json
